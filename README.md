### [TagMe — Privacy-First Social Recognition Platform](https://github.com/Mazen-wedaa/tagme-production)

> Users anonymously tag others with meaningful labels. Recipients can reveal rare tag senders once.

A production-grade monorepo built with Next.js 14, TypeScript, and Prisma. Features a three-tier tag system: **NARROW** (rare, usage-limited), **COMMON** (unlimited), and **EXTENDED** (categories). Full infrastructure support via Docker, Kubernetes, and Terraform.
